# Evidence index

Every claim in `docs/` resolves to one artifact. Artifacts live outside Git under
`$RUNS_DIR` (see `.env.example`); paths below are relative to that root.

Evidence classes follow `AGENTS.md`:

| Class | Meaning |
|---|---|
| `measured` | produced by a run whose log and output are retained |
| `documented` | quoted from an upstream document or source file |
| `inferred` | follows from measured data but was not itself measured |
| `not verified` | asserted or expected, with no retained artifact |

## Stage directories

| Stage | Directory under `$RUNS_DIR` | Contents |
|---|---|---|
| A | `A_smoke/` | renderer smoke report, per-camera PNGs, collection log |
| B | `B_contract/`, `B_replay/` | HDF5 and LeRobot contract reports, expert replay report + video |
| C | `artifacts/` (sibling of `$RUNS_DIR`) | normalization JSON, T5 cache index |
| D | `D_openloop/` | placement report, latency bench, official client output |
| E | `E_closed_loop/` | per-seed videos, `_result.txt`, action traces |
| F | `F_compare/` | GGUF inspect/validate output, C++ vs PyTorch inputs |
