# V0.1 — GWP 0.5 inference reproduction

Status: **PASS** — measured 2026-10-23. Evidence: see `docs/experiments/evidence-index.md`
rows D1–D3.

## Goal

Given a fixed model revision and one recorded observation batch, load the official GWP 0.5 policy and produce a finite action chunk. Measure inference latency and peak GPU memory, persist the input provenance and output, and plot the action sequence.

## Acceptance criteria

- [x] Record the GWP source commit, checkpoint manifest/hash, base model revision, runtime versions, device, and inference configuration.
      *The snapshot ships without Git metadata, so identity is pinned by content hashes instead of a commit — see `docs/experiments/upstream-sources.md`. Runtime versions: `docs/experiments/environment-lock.md`.*
- [x] Load the actual model weights and complete one real inference call.
      *13.47 GB allocated after load; 40 calls issued (10 warmup + 30 timed).*
- [x] Validate action shape, dtype, finite values, and expected action dimension/horizon against the pinned model contract.
      *`[48, 14]` float32, all finite, range `[-1.598, 2.395]` rad. Width 14 is the real action dimension; the checkpoint's action channel width is 16 with 2 zero-padded dims.*
- [x] Record warmup policy and at least 30 timed calls; report p50/p95 latency and peak allocated/reserved GPU memory.
      *10 warmup + 30 timed. model p50 674.9 ms / p95 702.9 ms; e2e p50 727.5 ms / p95 753.2 ms; peak reserved 13.98 GB.*
- [x] Save a machine-readable action chunk and a plot; record the observation source without embedding private resource paths.
      *`$RUNS_DIR/D_openloop/openloop_bench.{json,csv}` plus `server_timing.jsonl`; observation source is episode 0 / frame 0 of the converted dataset, referenced by index rather than by path.*
- [x] Provide a command that reproduces the run from environment variables and checked-in configuration.
      *`scripts/infer/gwp_server.sh` + `scripts/infer/openloop_bench.py` + `configs/experiments/v0.1-inference.yaml`.*

## Measured result

| Metric | p50 | p95 |
|---|---:|---:|
| Model forward | 674.9 ms | 702.9 ms |
| Preprocess | 6.5 ms | 8.2 ms |
| Postprocess | 1.7 ms | 4.7 ms |
| Transport | 43.4 ms | 48.6 ms |
| End to end | 727.5 ms | 753.2 ms |

The upstream report quotes 122 ms on an A800. That figure is not used as a gate
here: the four 4090s were running at 95–99 % utilisation from other users' jobs
during the measurement, so the two numbers are not comparable.

## Exclusions

This specification does not claim RoboTwin task success, SO101 compatibility, fine-tuning, C++ parity, or safe real-robot control. Those belong to `v0.2`, `v0.3`, and later specifications.

Zero-shot action error against the recorded ground truth was 0.169459 MSE over
ten chunks. It is recorded as an observation, not as an acceptance criterion.
