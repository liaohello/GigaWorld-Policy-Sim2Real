# V0.1 — GWP 0.5 inference reproduction

## Goal

Given a fixed model revision and one recorded observation batch, load the official GWP 0.5 policy and produce a finite action chunk. Measure inference latency and peak GPU memory, persist the input provenance and output, and plot the action sequence.

## Acceptance criteria

- [ ] Record the GWP source commit, checkpoint manifest/hash, base model revision, runtime versions, device, and inference configuration.
- [ ] Load the actual model weights and complete one real inference call.
- [ ] Validate action shape, dtype, finite values, and expected action dimension/horizon against the pinned model contract.
- [ ] Record warmup policy and at least 30 timed calls; report p50/p95 latency and peak allocated/reserved GPU memory.
- [ ] Save a machine-readable action chunk and a plot; record the observation source without embedding private resource paths.
- [ ] Provide a command that reproduces the run from environment variables and checked-in configuration.

## Exclusions

This specification does not claim RoboTwin task success, SO101 compatibility, fine-tuning, C++ parity, or safe real-robot control. Those belong to later specifications. No run has been performed for this repository scaffold yet.
